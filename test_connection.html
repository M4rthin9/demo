🔧 ทดสอบการเชื่อมต่อ Google Apps Script

ใช้หน้านี้เพื่อตรวจสอบว่าการเชื่อมต่อระหว่างเว็บไซต์และ Google Apps Script ทำงานได้ถูกต้อง

📌 คำแนะนำ: หากมีปัญหาการเชื่อมต่อ ให้ตรวจสอบตามลำดับดังนี้:
1. URL ของ Google Apps Script ต้องถูกต้อง
2. Google Apps Script ต้อง Deploy เป็น Web App
3. การตั้งค่า "Who has access" ต้องเป็น "Anyone"
4. ชื่อ Sheet ต้องตรงกับที่กำหนดไว้ในโค้ด

Staff Password (สำหรับการทดสอบที่ต้องการ authentication):

📋 รายการตรวจสอบ (Checklist)

  • URL ถูกต้องและเข้าถึงได้
  • Google Apps Script Deploy ถูกต้อง
  • Authentication ทำงานได้
  • Sheet "การจอง" มีอยู่และเข้าถึงได้
  • Column headers ถูกต้อง
  • สามารถอ่านข้อมูลได้

🚨 ปัญหาที่พบบ่อยและวิธีแก้ไข

⚠️ ปัญหา: ได้ response เป็น Unauthorized
วิธีแก้: ตรวจสอบว่า pass parameter ถูกส่งไปด้วยค่า '10900'
⚠️ ปัญหา: ได้ response เป็น empty rows
วิธีแก้: ตรวจสอบว่า Sheet มีข้อมูล และ column 'ref' มีค่า
❌ ปัญหา: Network error / CORS error
วิธีแก้: ตรวจสอบการ Deploy Google Apps Script:
- ต้อง Deploy เป็น "Web App"
- "Execute as" ต้องเป็น "Me"
- "Who has access" ต้องเป็น "Anyone"
❌ ปัญหา: Sheet name ไม่ตรง
วิธีแก้: เปลี่ยนชื่อ Sheet tab ให้เป็น "การจอง" หรือแก้ไขค่า SHEET_NAME ในโค้ด
